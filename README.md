
# TextLab 🌐

A lightweight text toolkit supporting Vietnamese and English.

## 📌 About the Project

TextLab is a simple web application that provides three useful text tools in one place.

## ✨ Features

- 🌍 Language Translator
  - Translate between multiple languages.
  - Automatic language detection.
- 📝 Word Counter
  - Count words.
  - Count characters.
  - Count characters without spaces.
  - Count sentences.
- 📡 Morse Code Converter
  - Encode text into Morse code.
  - Decode Morse code into text.
- 🌙 Dark Mode interface.
- 🌐 Vietnamese and English interface.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- MyMemory Translation API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `textlab.html` in your browser.
4. Start using TextLab!
